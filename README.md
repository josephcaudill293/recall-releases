# Recall for macOS

[Download the latest version](https://github.com/josephcaudill293/recall-releases/releases/latest/download/Recall-macOS.zip) · [Release notes](https://github.com/josephcaudill293/recall-releases/releases)

Recall runs on Apple silicon and Intel Macs with macOS 14 or later.

If you have Recall 0.1.10 or earlier, quit Recall and replace the existing app with the one in the ZIP. For later releases, use **Recall → Check for Updates…** when recording and playback are idle.

This repository hosts the app downloads and the signed update feed.
